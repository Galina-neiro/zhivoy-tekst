# Живой текст (zhivoy-tekst)

Скилл для Claude, который убирает из русских текстов привычки нейросети: «не просто X, а Y», канцелярит
(«является», «данный», «в рамках»), тройки ради ритма, кальки с английского, рекламный пафос, хвосты чат-бота.
Сделан дизайнером для своих постов, подписей, уроков и писем заказчикам.

Русская адаптация скилла [humanizer](https://github.com/blader/humanizer) (Siqi Chen, MIT).
Автор адаптации — Галина Салий, TG-канал [@galina_saliy_pro](https://t.me/galina_saliy_pro).

Внутри только текстовые файлы, без программ: их можно открыть и прочитать перед установкой.

## Как поставить

**Claude Code** — отправьте ему:

> Поставь скилл из https://github.com/Galina-neiro/zhivoy-tekst в папку .claude/skills/zhivoy-tekst этого проекта. Потом попроси у меня 2–3 моих текста и запиши их в голос.md, чтобы скилл писал моим голосом.

**claude.ai** (сайт или приложение): нажмите зелёную кнопку **Code → Download ZIP**, потом
Настройки → Возможности → Скиллы → Загрузить скилл и выберите скачанный архив.

## Подстроить под себя

> Прочитай скилл zhivoy-tekst и мой паспорт для нейросети. Подстрой примеры в скилле под мою нишу и добавь в него то, что меня бесит в чужих текстах.

Шаблон «Паспорт для нейросети» — в TG-канале [@galina_saliy_pro](https://t.me/galina_saliy_pro).
